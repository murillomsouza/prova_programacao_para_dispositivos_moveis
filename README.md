# Prova de Programação para Dispositivos Movéis
_______
## Desafio Proposto

Realizar um aplicativo com 3 telas (mínimo) e salvar dados localmente
usando um dos "Bancos" apresentados em aula. 

- [ ] Room
- [x] Shared Preferences
- [ ] OpenHelper + SQLite

O aplicativo conta com 1 tela inicial com 2 botões: Calcular Média Final
e Cadastrar Aluno. Abordando o conceito de navegação e salvamento de dados
locais.
